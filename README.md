A side-view digging machine game, built for the Luanti Game Jam 2026.

# Strata

Welcome to the planet Strata! So you signed a contract to get rich and didn't read the fine print, huh?

Time to pay off your debt. Dig through the layers of rock, sell your haul or refine it into upgrades for your machine, and go ever deeper for more valuable materials.

Will you manage to pay off your debt, or will something else catch your eye in the depths?

## Status

Strata is still a work in progress. More features are on the way, and the balance (fuel, prices, upgrade costs) will probably keep changing.

## Requirements

- Luanti 5.18.0 or newer

## Install

Copy or clone this folder into the `games/` directory of your Luanti install (or your user data directory), then pick **Strata** when creating a world.

## Source art

The `art/` folder holds the editable sources of the game's textures and nodeboxes. The `.nbx` files are projects of the [Luanti Nodebox Editor](https://github.com/ZenonSeth/luanti-nodebox-editor), open them there to edit and re-export.

## How it was made
- All the code was generated through claude code.
- Sound effects were generated with python scripts written by claude code.
- Music is from the amazing Kevin MacLeod (See license file for details)
- Art is a mixture of hand drawn in Krita, Affinity Photo 2, and some generation via python scripts based on sketches.
- Nodeboxes + their textures were made using the Luanti Nodebox Editor project (see above)
- Digger model was hand-made in Blockbench.
